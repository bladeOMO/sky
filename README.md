## 发布到 GitHub Pages

1. 在自己的 GitHub 账号下新建公开仓库，建议名称为 `sky-profile-chuandi`。
2. 将 `index.html` 和 `.nojekyll` 上传到 `main` 分支根目录。
3. 在仓库的 Settings → Pages 中，选择 Deploy from a branch，分支为 `main`，目录为 `/ (root)`，保存。
4. 等待 Pages 构建成功后，打开页面给出的站点地址，核对标题、手机布局、风格切换与复制按钮。
