## 后续添加资料

1. 将新资料 HTML 和其引用的图片、音乐上传到本仓库。每份资料使用不同文件名或独立文件夹，避免覆盖已有内容。
2. 在 `catalog.html` 中加入对应入口，并更新本说明。
3. 等待 GitHub Pages 部署成功后，核对页面、图片、音乐和手机布局。

当前 Pages 从 `main` 分支根目录发布。不要把不同人物的 HTML 都命名为根目录的 `index.html`。

## 资料来源

咖啡页面沿用仓库内已有 HTML，其中包含金山文档的原始资料入口。人物资料、插图和音乐保持现有文件内容；此次仅整理目录与访问入口。
